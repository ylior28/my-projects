🎰Digital Logic Design – Blackjack Game System
 
 ✳Overview Design and implementation of a complete Blackjack game system using Logisim.
 
 The project simulates real gameplay with logic circuits, registers, counters, and memory integration, while managing betting, dealer logic, and win/lose conditions. 
 
⚙️ Key Features 

Full Blackjack game flow: deal, hit/stand, win/lose handling Card control system with registers and counters Bank & betting management with digital logic Win/Lose detection including dealer vs. player comparison Score tracking & save to memory (LCD/Registers) Implementation of multiplexers, comparators, shift registers, priority encoders, and counters Modular design – each block (bank, cards, dealer logic, etc.) independently tested and integrated. 

🛠 Tools & Skills Logisim for circuit design and simulation Digital Logic Design (Combinational & Sequential Circuits) State Machine Design Modular hardware system integration Problem-solving & system-level thinking. 

📊 Outcome Delivered a working Blackjack logic system in Logisim that demonstrates advanced use of digital components, state machine control, and full system integration.
