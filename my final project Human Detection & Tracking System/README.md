📷💻🧠Developed an intelligent Human Detection & Tracking System as part of my final B.Sc. project in Electrical & Electronics Engineering. 
An intelligent human detection and tracking system designed for real-time surveillance. 

The system identifies people using a lightweight ML model, tracks their movement with a servo-controlled camera, and triggers safety alerts based on distance and behavior.

It combines machine learning, computer vision, and embedded hardware control into a unified smart-monitoring platform.

🔷Key Features: 

Real-time person detection using TensorFlow Lite (MobileNetV1-SSD). 

Servo-controlled camera for dynamic tracking. 

Ultrasonic sensor for distance measurement..

Interactive GUI (Tkinter) for manual/automatic control and live video feed. 

Automated alerts via buzzer, LED, and email (SMTP). 

Video recording using Picamera2 (MJPEG). 

Tools & Technologies: Python | OpenCV | TensorFlow Lite | Raspberry Pi 4B | Picamera2 | Tkinter GUI |threading

GPIO Applications: Smart surveillance, home security, sensitive-area monitoring, and integration in autonomous systems.
