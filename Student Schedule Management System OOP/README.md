📅 Student Schedule Management System
Final project in Object-Oriented Programming (OOP) with C++.

This project implements a student schedule management application using three approaches:

1.	Self Implementation – Full C++ implementation using STL and CSV files.

2.	GenAI (Claude/ChatGPT) – AI-assisted implementation with debugging and adaptation.

3.	Vibe Coding (Base44) – Low-code/no-code implementation based on defined requirements.

⚙️ Technologies

•	C++ (OOP, STL, exception handling, operator overloading)

•	CSV file handling for persistent storage

•	GenAI tools: Claude, ChatGPT

•	Vibe Coding (Base44) platform

✨ Features

•	Add, remove, and print schedules

•	Add or remove courses (lectures, tutorials, labs) to schedules

•	Display schedules in table format (days vs. hours)

•	Prevent duplicate course IDs using set

•	Store courses and lessons using map and vector

•	Save and load schedules persistently from CSV files

📚 Key Learnings

•	Designing and implementing OOP systems from scratch

•	Working with STL containers (vector, map, set)

•	Efficient debugging and error handling in C++

•	Leveraging GenAI tools for development support

•	Understanding trade-offs between manual coding, AI-assisted coding, and low-code platforms
