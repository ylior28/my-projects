🚙 Bluetooth-Controlled Smart Vehicle I developed a microcontroller-based vehicle controlled via Bluetooth communication, enabling speed and direction control through a mobile device. 

Key features include: 

•	Control & Processing – EFM32PG28 ARM Cortex-M MCU as the main controller. 

•	Locomotion – Two DC motors with PWM-based speed control. Bluetooth 

•	Communication – HC-06 module using asynchronous UART at 9600 baud for wireless commands. 

•	Obstacle Detection – Ultrasonic sensor for real-time distance measurement and automatic stop at <30 cm. 

•	Safety Mechanism – Emergency button that halts the vehicle instantly, with error indication on an LCD and green LED. 

•	User Interface – LCD screen displaying vehicle direction (Forward, Backward, Right, Left, Neutral, Stop) and distance from obstacles. 

This project strengthened my skills in embedded system design, real-time control, communication protocols UART and debugging hardware/software integration.
