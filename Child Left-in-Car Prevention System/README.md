🚗 Child Left-in-Car Prevention System I developed a smart system designed to detect and prevent children from being left unattended in vehicles. 

The system uses weight, temperature, and distance sensors, and if a child is detected in dangerous conditions, it triggers an alarm.
 
 The system was designed and implemented from block diagrams to a fully functional electrical circuit, using components such as ADC0804, DAC0800, LM35, GP2Y0A21YK0F, NE555, operational amplifiers, logic gates, and flip-flops. 
 
 This project provided hands-on experience in embedded hardware design, working with datasheets, real-time troubleshooting, and integrating multiple sensors for automated decision-making.
