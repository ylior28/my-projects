🖼️ Image Processing – Blurring and Restoration
This project explores image blurring and restoration techniques using both spatial and frequency domain approaches. The main goal was to create test images, apply Gaussian blurring, and restore sharpness using high-frequency filters and FFT-based inverse filtering.

⚙️ Technologies

•	C++ (pointer-based image processing for efficiency)

•	Convolution filters: Gaussian, High-Pass, and sharpening kernels

•	FFT (Fast Fourier Transform) for frequency domain filtering

✨ Project Highlights

•	Generated synthetic grayscale test images with text in varying font sizes

•	Applied Gaussian blurring with different σ values to simulate image degradation

•	Implemented spatial convolution with multiple high-pass and sharpening filters

•	Performed frequency domain blurring and restoration using FFT

•	Designed and tested inverse Gaussian filters for unblurring

•	Developed custom C++ functions for Gaussian filtering, Min-Max thresholding, and convolution

📊 Results

•	Demonstrated the trade-off between sharpening and noise amplification

•	Achieved partial restoration of blurred images using optimized filters

•	Showed the effectiveness of FFT-based filtering in the frequency domain

•	Highlighted the challenges of naive inverse filtering and the need for careful parameter tuning

📚 Key Learnings

•	Gained insight into the complexity of image restoration, balancing sharpness vs. noise

•	Practical experience with Fourier Transforms for image processing

•	Learned efficient memory management in C++ using pointer-based pixel access
