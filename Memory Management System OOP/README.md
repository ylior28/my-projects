# 💻💾Memory Management System Simulation This project simulates a **memory allocation system** using different allocation strategies implemented in C++ with OOP principles.
 
 ## ⚙️ Technologies - C++ (OOP, inheritance, exception handling) - Placement new operator - Linked list–based memory block management ## 

✨ Features - Implementation of a `Block` structure with split/merge operations - `MemoryManager` for allocation/deallocation of memory blocks 

- Allocation strategies: 

- **First Fit** – allocate the first suitable free block

 - **Best Fit** – allocate the smallest suitable block 

- **Worst Fit** – allocate the largest suitable block 

- Memory simulation tool to measure: 

- Allocation success rate 

- Memory utilization efficiency 

- Correct handling of free/merge operations

 - Edge case behavior 

## 📊 Results - Verified correct implementation of memory allocation algorithms - Demonstrated trade-offs between **First Fit, Best Fit, and Worst Fit** strategies 

- Showed effective block splitting/merging without memory leaks

 - Gained insights into memory fragmentation and allocator efficiency 

## 📚 Key Learnings - Designing a memory management system with OOP 

principles - Implementing allocation strategies in an abstract and reusable way 

- Handling memory fragmentation and edge cases 

- Applying `placement new`, operator overloading, and exception safety in C++
